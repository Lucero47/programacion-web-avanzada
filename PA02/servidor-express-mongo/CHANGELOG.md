# Changelog

## 1.1.0 — PA3

- Se añadieron registro, inicio y cierre de sesión con JWT y contraseñas protegidas mediante bcrypt.
- Se aplicaron permisos de administrador, editor y lector en la API y en la interfaz Angular.
- Se añadió administración de usuarios y roles para administradores.
- Se incorporó un panel React con React Router, Hooks, Context y Axios, conectado a la misma API y base MongoDB.
- Se añadieron pruebas de seguridad sin conexión a base de datos, datos de muestra, guía de pruebas y configuración de despliegue para Render.
- Se documentaron instalación, ejecución local, variables de entorno y rutas de la API.
